QUICK START
How MicroAI Studio works

          

            
01
Train
Use Google Teachable Machine to train image classes such as HAPPY, SAD and MAYBE.

            
02
Load
Paste the model URL into AI Lab. MicroAI Studio loads the model directly in your browser.

            
03
See
Start the camera. Predictions and confidence update live without sending camera frames to the server.

            
04
Map
Map each class to a micro:bit command. The default examples use HAPPY, SAD, MAYBE and CLEAR.

            
05
Connect
Flash the generated Bluetooth UART program to your micro:bit, then connect from a compatible Chrome/Edge browser.

            
06
Build with AI
Sign in to sync projects and use the server-side OpenAI assistant without exposing your API key.

          

          
Browser note: Web Bluetooth generally requires a supported Chromium browser and a secure context such as HTTPS. GitHub Pages is suitable for the frontend.
