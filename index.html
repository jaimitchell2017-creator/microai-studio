05 / GUIDE
Build your first AI micro:bit

      

        
01
Train
Open Teachable Machine and create an Image Project. Make classes such as Thumbs Up, Thumbs Down and Maybe. Capture lots of examples from different angles and lighting.

        
02
Export
Choose Export Model and use the hosted/shareable model option. Copy the model URL and paste it into MicroAI Studio.

        
03
Code
Copy the MakeCode JavaScript from this page into the micro:bit MakeCode editor. Flash it to your micro:bit.

        
04
Connect
Pair/connect the micro:bit using the Connect button. If your browser does not support Web Bluetooth, use the MakeCode code directly or a supported device/browser.

        
05
Map
Choose what each AI class should do. Thumbs Up can show a happy face, Thumbs Down a sad face, and Maybe a question mark.

        
06
Go!
Start the camera. Hold up your trained gesture. When the prediction passes the confidence threshold, the action is sent to the micro:bit.
